# Mikee Gadget Plug — system audit for the 13-fix upgrade (15 Nov 2026)

## What the site actually is
- **No framework.** Static HTML is generated by Node scripts (`npm run build`) from `templates/home.html.template`
  and the catalogue in `commerce/retail-inventory.mjs`; behaviour is plain ES modules in `assets/`.
- **Hosting:** Vercel. 12 serverless functions in `api/` (the Hobby limit, all used), so new server features were
  added to existing routes, plus one edge `middleware.js`.
- **Database:** Supabase Postgres. Tables have RLS on with no policies (server-only access through the service key).
- **Prices and availability — the source of truth** is `checkout_inventory` (`sku`, `price_ngn`, `enabled`,
  `product_data`). Checkout prices orders inside the database (`shop_create_order_deals`); the browser's price is
  never trusted. `retail-inventory.mjs` mirrors it for page generation.
- **Payments:** Paystack (TEST key; a live key is refused unless `SHOP_LIVE_PAYMENTS=true`) and Credit Direct
  (live, widget + signed transaction + svix-verified webhook). Neither was changed by this work.
- **Admin:** `/admin/`, magic-link sign-in for one owner email, every API call re-checks the token and `shop_admins`.

## Not possible or deliberately not done
- **Customer sign-in** does not exist (only the administrator can sign in). The account page offers saved items on the
  device and order tracking by reference; wishlist sync across devices needs customer accounts first.
- **Automatic photo discovery** is not connected to any licensed image source, so it is a manual upload/import flow.
- **Automatic stock decrement/reservation** is not implemented; quantities are administrator-maintained.
- Legacy "Easy Buy" landing pages (`/iphone-easy-buy`, `/phones-on-installment`, the old calculator) still exist and
  need an owner decision; the code and records were left in place.
